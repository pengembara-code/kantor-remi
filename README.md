# Kantor Remi 🏢

AI model usage monitoring — real-time dashboard tracking requests, latency, success rate, and availability status across multiple LLM providers.

- **Kantor AI** (`index.html`): visualisasi kantor — para model jadi karyawan chubby dengan status KERJA / ISTIRAHAT / KENA LIMIT.
- **Dashboard** (`dashboard.html`): statistik pemakaian, grafik, dan riwayat.

Data diperbarui otomatis setiap 5 menit.
